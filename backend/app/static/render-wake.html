Application Overview

SpeakBetter backend · FastAPI · Gemini 2.5 · MongoDB Atlas (Render free tier)

FREE TIER

Free-tier web services on Render sleep after 15 minutes of inactivity. The first request after a sleep triggers a cold start that can take 40–80 seconds before the container accepts traffic. This monitor pings the health endpoint continuously, then hands off to the live app once the instance is online.

•Cold Start Latency — container spin-up blocks the first request.
•Database Pooling — MongoDB connection must re-establish on wake.
•API Rate Limits — Gemini quota resets per minute; burst on boot.
•State Sync — in-memory caches rebuild after instance restart.

Free-tier servers may take 40–80 seconds to wake up and start the app.
